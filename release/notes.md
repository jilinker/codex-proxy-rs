# v3.13.1+2

## 新增功能

- 分组管理增加 Key 授权图标和多选弹窗 仅管理员可授予或撤销整组账号的查看与操作权限 授权关系独立于路由绑定
- 授权 Key 可查看已启用授权分组内的全部账号 显示完整名称与邮箱 并使用个人信息 额度刷新 重置卡和额度预测
- Key 账号操作使用独立接口 每次请求重新校验会话与授权 停用分组 停用 Key 撤销授权或移除成员后立即影响后续请求

## 体验与安全

- 复用管理端的额度面板 个人信息 重置卡及预测组件 账号默认收起 未授权账号保持脱敏只读 不开放账号编辑 删除 凭据或代理配置
- 重置卡复用现有业务服务的并发控制和幂等重试 前端待确认操作按登录身份隔离 Key 操作记录独立审计身份
